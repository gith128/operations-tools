People

Messages to staff

A message shows at the top of every phone's home screen until each person taps Got it. An urgent one is red, and also stays at the top of the Group Scanner until you withdraw it. Staff don't see who else has read it; you do, below. Messages drop off after 30 days, or when withdrawn.

Team

The names staff pick from with the 👤 button. Staff only ever see each person's Known as name and initials; full name, email and mobile stay here, for emailing the roster and texting about changes. People who leave are retired, so their name stays on old records.

Day to day

Rezdy products

Every product name seen in a manifest, and the location it goes to with the current matching words. Matching words are set for each location in Asset Register → Locations, or tried and saved below. A product that matches more than one location, or none, is flagged.

Try matching

Paste product names (one per line) or choose a Rezdy manifest to see where each would go. Leave it empty to test every product seen. To try different words for a location, choose it and edit its words: nothing changes until you tap Save these words.

Fleet

Fleet history and dashboard data

Each bike's day (available, hired and where from, out of service, in storage) is recorded when the next day's manifest is loaded, and the Fleet report and Dashboard read those records. Rebuild fills in earlier days from the daily archives, the move history, the issue log and the register's change history, so the figures describe each day as it was. Days recorded on the day are never changed. Where a rebuilt day had to use today's model or an unknown location, the report says so.

Preview first: it reads everything and shows what would be saved, month by month, without saving. Then Save. Both are safe to run again.

Data and safety

Backups

Loading…

A checked backup of everything (groups and contacts, issues, the register, M-checks, checklists, lost property with photos, settings and the daily archives) is taken automatically each night. Backups are kept every night for 30 days, the first of each month for a year, and ones taken with Back up now for 90 days.

Restore

Choose a backup, then the parts to put back. A safety backup of the data as it is now is taken first, so a restore can itself be undone.

    Archived days

    A copy of the scanner groups is saved automatically each time a new manifest is loaded or the scanner is reset. Each archive opens as a spreadsheet (CSV): one row per bike, with its group, scan time and anything taken off. Customer phone numbers are not included.

      Business

      Business

      The business's name, logo, colours and heading font, shown on every page. Each phone keeps a copy, so pages never wait for them; the home screen picks up a change straight away, other screens within a few hours (or when reopened from the home screen).

      No logo

      PNG or JPEG. It's shrunk to suit phones (about 50 KB at most). A square or upright mark works best beside the name.

      Guests and sites

      QR codes for guests

      The codes on the Show QR screen, and the links staff can send from Today's Contacts. One per line: the name, then a |, then the link (it must start with https://).

      Message templates

      The messages staff send guests from Today's Contacts and the Group Scanner. These fill themselves in: {first} the guest's first name, {site} where they're hiring from, {time} their start time, and {weather}, which staff describe when they send it (keep it in the weather message).

      Site checklists

      Edit the opening and closing checklists for each site: one item per line, in the order staff work through them. Start a line with * to make it mandatory: it must be ticked as done before the checklist can be signed off. Records already signed off keep the wording they had.

      Locations

      Hire, delivery, collection and storage locations, and the words that match them to Rezdy products, are kept in the Asset Register → Locations, next to the bikes. They're included in the configuration file.

      Maintenance

      Fault types

      The fault types staff choose from when logging an issue, and that M-check failures are logged under. Rename one in place; its issues keep it. A type you no longer want can be retired: it leaves the list but stays on the issues that used it. Repeat faults are the same type logged again on the same bike within the window below.

      Home screen

      The order of the tools on the home screen, and which are shown, for every phone. A hidden tool still opens from its address (for example /qr). Load Manifest is always shown, because Admin is opened from it.

      Configuration file

      Configuration file

      Everything on this page in one small file: the business details, fault types, home screen, QR codes, messages, site checklists and locations. Keep a copy with your backups. Loading one puts back the parts you choose, after taking a backup first; hire records, issues and the asset register aren't touched. It's also how a new installation is set up.
